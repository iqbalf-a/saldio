Kebijakan Privasi

Terakhir diperbarui: 22 Agustus 2026

Ringkasnya
  • Saldio tidak punya server. Data keuangan Anda tersimpan di perangkat Anda sendiri.
  • Sinkronisasi ke Google Drive bersifat opsional, dan filenya masuk ke folder privat milik akun Google Anda — bukan milik kami.
  • Tidak ada iklan, analytics, pelacakan, atau penjualan data.
  • Kami sebagai pengembang tidak bisa melihat catatan keuangan Anda.

1. Tentang aplikasi ini

Saldio adalah aplikasi catatan keuangan pribadi — dompet, transaksi, aset, tabungan emas, dan anggaran. Aplikasi ini dikembangkan secara perorangan oleh Moh Iqbal Firman Ardiansyah.

Kebijakan ini menjelaskan data apa yang diproses aplikasi, di mana disimpan, dan apa yang bisa Anda kendalikan.

Semua data di bawah ini berasal dari Anda sendiri — tidak ada yang dikumpulkan diam-diam di latar belakang.

Foto struk

Jika Anda melampirkan foto struk, gambar diambil dari kamera atau galeri, lalu diperkecil hingga sisi terpanjang 1280 piksel dan dikompres menjadi JPEG. Hasilnya disimpan menyatu dengan catatan transaksi Anda di perangkat. Foto tidak dikirim ke pihak mana pun.

Impor PDF

File PDF yang Anda pilih dibaca dan diurai sepenuhnya di dalam perangkat Anda. Isinya tidak diunggah ke server mana pun.

PIN aplikasi

PIN tidak disimpan dalam bentuk aslinya. Yang disimpan adalah hasil hash-nya. PIN juga dipakai untuk menurunkan kunci enkripsi data Anda. Karena kunci itu berasal dari PIN Anda, PIN yang lupa tidak bisa kami pulihkan.

3. Sinkronisasi Google Drive opsional

Anda bisa memilih untuk login dengan akun Google agar data tersinkron antar perangkat. Jika Anda tidak login, Saldio tetap berfungsi penuh secara offline.

Izin yang diminta

  • openid, profile, email — untuk mengenali akun yang login dan menampilkan nama serta email Anda di aplikasi.
  • drive.appdata — untuk menyimpan satu file data (saldio-data.json) ke folder aplikasi tersembunyi di Google Drive Anda.

Yang penting Anda tahu soal drive.appdata

  • File disimpan di appDataFolder — area khusus di dalam Google Drive milik Anda sendiri.
  • Folder ini tersembunyi dari tampilan Drive biasa dan terpisah dari file-file Anda yang lain.
  • Izin ini tidak memberi Saldio akses untuk membaca dokumen, foto, atau file lain di Drive Anda. Secara teknis, Saldio hanya bisa melihat file yang dibuatnya sendiri.
  • Data tidak melewati server pengembang. Aplikasi berkomunikasi langsung dari perangkat Anda ke Google Drive API.

4. Keamanan

  • Jika Anda mengaktifkan PIN, data akan dienkripsi dengan AES-GCM 256-bit. Kunci diturunkan dari PIN Anda memakai PBKDF2-SHA256 dengan 100.000 iterasi dan salt acak per perangkat.
  • Salinan yang tersimpan di Google Drive ikut terenkripsi selama PIN aktif.
  • Layar kunci PIN memberi jeda tunggu yang makin panjang setelah percobaan gagal berulang, untuk menghambat tebakan berturut-turut.
  • Koneksi ke Google Drive memakai HTTPS.

Tidak ada sistem yang sepenuhnya kebal. Jaga keamanan perangkat dan akun Google Anda, dan jangan bagikan PIN kepada siapa pun.

5. Yang tidak kami lakukan

  • Tidak ada server milik pengembang yang menyimpan data Anda.
  • Tidak ada SDK analytics, pelacak perilaku, atau crash reporting pihak ketiga.
  • Tidak ada iklan dan tidak ada ad network.
  • Data Anda tidak dijual, disewakan, atau dibagikan untuk keperluan pemasaran.
  • Tidak ada pengumpulan lokasi, daftar kontak, maupun daftar aplikasi terpasang.

6. Izin perangkat

  • Kamera — hanya aktif saat Anda memilih memotret struk.
  • Galeri / foto — hanya aktif saat Anda memilih gambar struk dari galeri.
  • Akses berkas — hanya aktif saat Anda memilih file PDF untuk diimpor atau menyimpan hasil ekspor.

Semua izin diminta saat dibutuhkan, dan bisa Anda tolak tanpa menghilangkan fungsi utama aplikasi.

7. Layanan pihak ketiga

Satu-satunya pihak ketiga yang terlibat adalah Google, dan hanya jika Anda memilih login untuk sinkronisasi:

  • Google Sign-In (OAuth 2.0) — proses masuk akun
  • Google Drive API — penyimpanan file data di Drive Anda sendiri

Penggunaan layanan tersebut tunduk pada Kebijakan Privasi Google.

Versi web Saldio dihosting di Vercel. Seperti hosting web pada umumnya, penyedia hosting dapat mencatat log akses teknis standar seperti alamat IP dan jenis peramban. Log ini tidak berisi catatan keuangan Anda dan tidak kami gunakan untuk membuat profil pengguna.

8. Berapa lama data disimpan

Data bertahan selama Anda menyimpannya. Kami tidak memegang salinan apa pun, sehingga tidak ada masa retensi di sisi kami. Data lokal hilang saat Anda menghapusnya atau mencopot aplikasi; salinan Drive bertahan sampai Anda menghapusnya sendiri.

9. Hak Anda dan cara menghapus data

Mengekspor data

Buka Backup & Restore di aplikasi, lalu pilih Export Data. Anda akan mendapat file berisi seluruh catatan Anda, dan bisa mengenkripsinya dengan PIN.

Menghapus data di perangkat

Buka Profil → Hapus semua data. Seluruh dompet, transaksi, dan riwayat harga akan dihapus permanen dari perangkat tersebut.

Menghapus salinan di Google Drive

Perlu diperhatikan: tombol "Hapus semua data" di atas hanya membersihkan perangkat, tidak menyentuh salinan di Drive.

Untuk menghapus salinan yang ada di Google Drive sekaligus mencabut akses Saldio:

  1. Buka myaccount.google.com/permissions
  2. Pilih Saldio pada daftar aplikasi pihak ketiga
  3. Klik Hapus akses — data tersembunyi milik aplikasi ikut terhapus bersamanya

Anda juga bisa mengelolanya lewat Google Drive: Setelan → Kelola aplikasi → Saldio → Hapus data aplikasi tersembunyi.

Kalau Anda mengalami kesulitan menghapus data, hubungi kami di alamat pada bagian 12 dan kami akan bantu memandu langkahnya.
