Pertanyaan umum

Apakah harus login untuk memakai Saldio?

Tidak. Saldio berfungsi penuh tanpa login — semua data tersimpan di perangkat Anda. Login dengan Google hanya diperlukan kalau Anda ingin data tersinkron antar perangkat.

Data saya disimpan di mana?

Di penyimpanan lokal perangkat Anda. Kalau sinkronisasi diaktifkan, satu file bernama saldio-data.json juga disimpan di folder aplikasi tersembunyi pada Google Drive milik akun Anda sendiri. Tidak ada server pengembang yang menyimpan data Anda. Detailnya ada di Kebijakan Privasi.

Saya lupa PIN. Bisa dipulihkan?

Sayangnya tidak bisa. Kunci enkripsi diturunkan langsung dari PIN Anda dan tidak pernah disimpan di mana pun, jadi tidak ada jalan pintas untuk memulihkannya — termasuk oleh kami.

Kalau Anda punya file ekspor yang belum terenkripsi, Anda bisa hapus data lewat Profil → Hapus semua data, lalu impor ulang file tersebut.

Kenapa Saldio minta izin Google Drive?

Untuk menyimpan satu file backup di area appDataFolder Drive Anda. Izin ini sengaja dipilih karena cakupannya paling sempit: Saldio hanya bisa melihat file yang dibuatnya sendiri, dan tidak bisa membaca dokumen, foto, atau file lain di Drive Anda.

Bagaimana cara memindahkan data ke HP baru?
  1. Cara paling mudah: login dengan akun Google yang sama di HP baru, data akan tersinkron sendiri.
  2. Tanpa login: buka Backup & Restore → Export Data di HP lama, pindahkan filenya, lalu Import Data di HP baru.
Impor PDF mutasi saya gagal terbaca. Kenapa?

Format mutasi tiap bank berbeda-beda, dan pembacanya baru mengenali sebagian format. PDF hasil pindaian (gambar) juga belum bisa dibaca karena tidak mengandung teks.

Kalau format bank Anda belum didukung, kirimkan email ke kami dengan menyebut nama banknya. Jangan lampirkan file mutasi asli — cukup sebutkan banknya, nanti kami tanyakan potongan contoh yang sudah disamarkan bila diperlukan.

Bagaimana cara menghapus seluruh data saya?

Di perangkat: Profil → Hapus semua data.

Salinan di Google Drive terhapus terpisah, lewat myaccount.google.com/permissions → pilih Saldio → Hapus akses.

Apakah Saldio berbayar atau ada iklan?

Tidak keduanya. Saldio gratis, tanpa iklan, tanpa pembelian dalam aplikasi, dan tanpa langganan.
